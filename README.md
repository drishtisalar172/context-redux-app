# Context API and Redux Toolkit Experiment

## Aim
To develop state management workflows using React Context API and Redux Toolkit.

## Description
This project demonstrates the use of:
- React Context API for authentication
- Redux Toolkit for product management
- Role-based access control (Admin and User)

## Features
- Login and Logout using Context API
- Product add and delete using Redux Toolkit
- Role-based UI rendering
- Single Page Application without page reload

## Technologies Used
- React
- Context API
- Redux Toolkit
- JavaScript

## How to Run
1. Install Node.js
2. Clone the repository
3. Run `npm install`
4. Run `npm start`
